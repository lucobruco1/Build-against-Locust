Build to Survive the Locust — wrong directory published

The entry point is index.html at the repository root, not public/index.html. It loads public/js/main.js, and imports shared/, core/, ai/ and game/ as modules, because the browser and the Node server run the same files. Publishing only public/ hides four of those five trees, so the page cannot boot.

Set the publish directory to . (the repo root) — netlify.toml at the root already does that — and don't add a /* /index.html rewrite, which would answer every .js request with this document and make the module loader fail while every request still reports 200.
